# Contributing to Zhaiylym

Thank you for your interest. The project is at concept stage, so the most useful contributions right now are ideas, corrections and local knowledge.

## Ways to help

- Open an issue to report a mistake or suggest an idea.
- Improve the documentation or add a Kazakh or Russian translation.
- Share what herders or rangeland specialists need from a tool like this.

## How to submit a change

1. Fork the repository and create a branch.
2. Make one focused change.
3. Open a pull request that explains what changed and why.
4. Say whether AI tools were used, and how you checked the result.
5. A maintainer reviews it before merging.

## Rules

- By contributing, you agree that your work is licensed under the [Apache License 2.0](LICENSE).
- Never add real herd locations or personal data to issues, pull requests or test files.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
