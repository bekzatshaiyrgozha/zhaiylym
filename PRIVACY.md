# Privacy and Data Plan

> This is a plan. The app does not exist yet and collects no data today.

## Principles

- Collect only what a grazing plan needs.
- Keep personal data on the user's phone by default.
- Share anything only after clear consent, which can be withdrawn.

## Planned data

| Data | Why | Where it stays | Public? |
| --- | --- | --- | --- |
| Grazing plan | Core feature | On the phone | No |
| Exact herd location | Plan routes | On the phone | Never |
| Pasture observation | Improve estimates | Shared only with consent | Only as an anonymous area |
| Satellite vegetation data | Pasture estimates | Public source | Yes |

## Safeguards

- Public maps show grouped areas, never a family's exact position.
- Data sent to a server is encrypted in transit.
- Users can export or delete their data.
- Individual records are never sold or given to lenders, buyers or advertisers.
- Before launch, the maintainer will check the plan against Kazakhstan's personal data law.
