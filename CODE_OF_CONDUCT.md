# Code of Conduct

Zhaiylym adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Everyone taking part in this project is expected to follow it in issues, pull requests, discussions and other project spaces.

## Do no harm

Because this project concerns rural communities and their land, contributors must also not:

- publish a person's location, herd size or other private details;
- use the project to accuse, shame or threaten a named person or family;
- present uncertain forecasts as facts when people may act on them.

## Reporting

Report a problem privately to a maintainer listed in [GOVERNANCE.md](GOVERNANCE.md). Do not post private details in a public issue.
